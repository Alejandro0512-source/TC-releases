# TC — instaladores

Versiones publicadas de **TC**, un gestor de archivos de dos paneles para Windows, al estilo Total Commander.

Este repositorio solo tiene los instaladores (en **Releases**). La app instalada busca aquí, al abrirse, si hay una versión nueva, y se actualiza sola.

- `TC-instalador-X.Y.Z.exe`: se instala y se actualiza sola.
- `TC-portable-X.Y.Z.exe`: no se instala; para actualizarla, reemplaza el .exe.
